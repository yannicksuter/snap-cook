{% comment %} SPDX-License-Identifier: AGPL-3.0-or-later The chart's look and behaviour, shared by the recipe page and its print page. The core renderer gives every node a class (ingredient, step, state, dish) and every part of a label one too (n: a step's number, qty: an amount, time and temp: a step's chips), and no colours; they are set here. Label styles are not scoped to #chart: Mermaid measures each label to size its shape, and they must apply while it does. Mermaid draws a chart only once it can be seen, after the font has loaded: a chart drawn in a closed
or in a fallback font comes out squashed. It draws again after every HTMX swap, because a swapped-in 
 is
new DOM it has not seen, and says "chart:drawn" when it is done, which the print
page waits for.
