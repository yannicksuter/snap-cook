# FAO/INFOODS Density Database v2.0

**Free download, attribution expected.** Not share-alike.

638 foods with mass density, bulk density and specific gravity — built by the
FAO expressly for volume-to-weight conversion, which is exactly our gap. Feeds
`density_g_per_ml`.

Only 638 entries, but they cover the common cooking ingredients well. Where
"flour" is too coarse for baking, per-ingredient overrides are added manually
with `source: manual`.

See `../manifest.yaml`.
